先说结论：这四个平台不是一个方案的四个投放位，是四件不同的事。小红书让人当场用上一条，抖音让书名进脑子，B站把人送到下载页，X 让这本书被当成一份公开数据转出去。用同一套内容铺四个平台，四个都不会起量。

一、动手前有三个坑，按顺序填

坑 1 · 最后一米

GitHub Pages 在国内不挂梯子打不开，或者慢到放弃

小红书和抖音来的绝大多数人，是下班路上刷到、用手机流量、没有梯子的人。让他们打开 goodseafly.github.io，多数人会在十秒后关掉。现在 2,086 次浏览能换来 291 个 star，是因为来源集中在 X（t.co 一家占独立访客三成）和 GitHub 站内，这些人本来就在能上 GitHub 的环境里。往小红书铺量之后，这个转化率会立刻塌掉，不是内容不行，是页面打不开。

先自测：手机关掉 Wi-Fi，用 4G，不挂任何代理，打开 Pages 首页，掐表。超过 5 秒没出完整目录，就算不能投。

要填这个坑，三条路，按成本从低到高：

  • 语雀 / 飞书公开知识库（推荐）：把 32 节按目录拆进去，PDF 和 EPUB 当附件挂上。国内直开、有搜索、能分享到微信，半小时能建完。缺点是内容要重新搬一遍，得写个导入脚本。
  • 腾讯文档公开链接：只放 PDF 和下载说明，不做在线阅读。十分钟搞定，适合先用着。缺点是下载量大了会提示频繁。
  • 自建静态站：买台国内轻量服务器，把离线 HTML 版扔上去。最稳，但要域名备案，这条路一个月起步。

这条不做，后面三个平台的活都白干。它是排在第一位的，不是"顺便优化一下"。

坑 2 · 你看不见效果

四个平台里，只有 B站和 X 能归因到具体来源

GitHub 的 Traffic 只给来源域名，Pages 没有统计代码。所以：

X
链接被折成 t.co，来源记在 t.co 名下，能看次数和独立人数。已有数据：408 次 / 348 人。
B站
简介和专栏里的链接点出去，来源记成 bilibili.com。这是唯一能算出"播放到下载"转化率的平台。
小红书 / 抖音
不放链接，用户靠自己搜书名。来源会变成 google.com、bing.com 或者直接空。分不出是哪个平台带来的。

所以顺序不是"哪个平台人多先发哪个"，是先发能测的，用测出来的结论去调不能测的。B站和 X 各发一轮，看清楚什么钩子能把人送到下载页，再把同一批钩子拿去小红书。

小红书和抖音也不是完全瞎：Star 的日增量是唯一可信的信号。现在是日均 3 到 10 个，如果某个平台发出去后连续三天站上 20，那就是它起效了；没变化就是没起效。别用点赞数判断，点赞和下载没关系。

坑 3 · 落点写错了

"576 条"是劝退句，不是卖点

576 条对写书的人是成就，对刷手机的人是负担。人会想：这么多，我这辈子看不完。所以他连第一条都不会看。

四个平台的落点都应该是同一句话：你现在只需要这一条。576 条只在两个地方出现——B站的"我做了件什么事"叙事里，和 X 的"结构化数据"叙事里。因为那两处的读者要的正是"量大且有序"，小红书和抖音的读者要的是"解决我眼下这一件"。

二、小红书：不推书，做速查号

小红书的用户行为是搜索加收藏。她不会搜"职场指南"，她搜"被裁了怎么算赔偿""年假没休完怎么办""试用期工资能低于八折吗"。所以这个号的定位不是"一本书的官方号"，是一个能搜到答案的账号。书的出现位置固定在正文最后一段，一句话，不占开头。

一条笔记只讲一条规定

结构固定四段：她遇到的事 → 规定怎么说（带出处）→ 具体的数怎么算（给公式或分档）→ 一句"类似的两百多条收在这本书里，搜《高性价比职场指南》"。

标题写她打进去的那句话，不写结论。判断标准：这句话她自己会不会在搜索框里敲。比如"年假没休完能折钱"她不会搜，她搜"年假没休完怎么办"。

封面只放一件事

一句话加一个数字，不放书名，不放"576 条"，不放二维码。前 3 张图承担全部留存，第 1 张给结论，第 2 张给出处，第 3 张给算法。已有那 7 张 1080×1440 的截图能直接用，但要把页码和导航条裁掉，只留正文那一块。

节奏

隔天一条，一轮 6 条，一轮做完停下来看数据。哪一条的收藏数是同批平均的两倍以上，就把那条拆成一个系列（同一个主题往下挖 5 条）。别一次发满，小红书连续发同类内容会掉流量池。

不能做正文里出现链接、二维码、微信号、"私信我""评论区扣 1""免费领取"。站外导流是封号级的问题，一本书不值得赌一个号。

三、抖音：只负责让书名进脑子

抖音是推荐流，看的是前三秒和完播率，用户不搜索、不点外链、不下载文件。所以这个平台的 KPI 只能是"播放量"和"书名被记住"，指望它带来下载是错的。

它不吃"我写了本书"

手里那条 60 秒竖屏片（1080×1920，v4）讲的是这本书是什么，放在抖音属于自夸，完播率会很低。抖音要的是另一种开场：一个具体的人、一个具体的数、一个她可能正在亏的钱。

抖音开场句式（前 3 秒必须说完） 公司让你签放弃加班费的协议，签了也不算数。
你试用期工资拿八成，这是合法的；拿七成，不是。

反过来说，凡是开头出现"今天给大家推荐一本书""我整理了一份资料"的，在抖音上都可以直接删掉重写。

用图文，不拍视频

抖音的图文有独立流量池，制作成本几乎是零——现成的 12 张卡片（promo/cards/c1-c5, s1-s7）换个顺序就能发一套。一套 6 到 7 张：第 1 张抛问题，中间几张给规定和算法，最后一张只写书名，不写链接。

配文 60 字以内，一句话说清这条能省多少或能拿多少，剩下全交给图。标签三个够了：#劳动法 #打工人 #职场。

量控制在最低

一周两条，一条十分钟。理由很直接：抖音带来的人几乎不会离开 App 去下载一本书，投再多也是播放数字。它的作用是当有人在小红书或别处听到书名、回来搜的时候，抖音上有一条能对上号。

不能做"免费领取""评论区留言送""加我发你"。这类话术在抖音是引流判定，而且这本书本来就不需要领取——它是公开网页，说"搜书名就能看"比"我发给你"干净得多。

四、B站：唯一能算转化率的地方

B站的用户愿意看十分钟，愿意点简介里的链接，也不排斥 GitHub。所以这里不是曝光位，是转化主力。如果只能做一个平台，做这个。

第一个视频讲"我干了件什么活"，不讲书

B站最吃的叙事是苦工：一个人翻了几百份文件，把散在各处的东西归到一处。这个叙事天生适合这本书，因为它是真的——576 条、885 处链接、A/B/C 三级标注。视频里最重要的镜头不是封面，是屏幕录制：真的打开一份文件，真的翻到那一条，真的点开一个链接看到原文。观众要看见证据，不是听见承诺。

三十分钟能剪出来的结构：为什么要做（三句话）→ 怎么分级（A 是什么、B 是什么、C 为什么只有 7 条）→ 现场演示三条（翻文件、点链接）→ 怎么用（搜、挑一条）→ 结尾给地址。时长 8 到 12 分钟，别更长。

三个选题按顺序发

第 1 条
我把三百份劳动法规读完了，整理出 576 条　—　建立信任，讲方法和分级，不推书。
第 2 条
N、N+1、2N 到底怎么算　—　一条一条算给镜头看，这是最容易被收藏和转发的实操题。顺带说清"N+2 没有法律依据"。
第 3 条
应届生签三方之前要问清的 8 件事　—　十月十一月是秋招，这条有时效。素材已经在《定位与宣传方案》的 60 条清单里。

专栏同步搬长文

B站专栏能被搜索引擎收录，是长尾最省力的一块。把小红书的长文改写成 1,500 字左右的专栏，标题用能被搜到的说法（"未休年假 300% 怎么算"），文末放网页地址。视频发完当天就发专栏，同一批人看视频，搜的人看专栏。

五、X：把它当公开数据发，不当书发

中文职场内容在 X 上没有多少读者，硬推是浪费。这本书在 X 上真正值钱的地方是形态：576 条结构化条目、每条一个出处链接、CC BY 4.0、可转载可改编。这是开源圈和数据圈会转的东西。

一条推只讲一件事：我把规定拆成了可核对的数据

英文单条（配 og.png） 576 Chinese labor rules, each with what it costs you, what you get back, and the exact article it comes from. 518 cite statutes or official statistics; every link goes to the source text. Free, CC BY 4.0.

不写"我写了一本书"，写"我做了一份能核对的数据"。前者在 X 上没人转，后者会被当工具转。

串的结构

四到六条：第一条给结论和数字，第二条给三个具体例子（每条一句、带条款号），第三条讲分级方法（A 是什么、C 为什么只有 7 条），第四条讲授权和下载，最后一条放链接。链接永远在最后，X 会把它折成 23 字符，放前面浪费位置。

不做的三件事

不 @ 任何大 V 求转发，不参与互推群，不在别人的推下面贴自己的链接。这三件事在 X 上会被当成 spam，而且和之前定下的规矩一致——不打扰别人。

什么时候该停

B站
视频 7 天播放不到 1,000，说明选题不对，不是平台不对。换题，别加量。
小红书
6 条里没有任何一条收藏过 50，说明钩子不成立，回去改标题和封面，先别发第 7 条。
抖音
连续 4 条播放都低于 500，停掉。这个平台的账号权重不够，不值得为它耗时间。
X
一条 thread 出去 48 小时没有一次来自非关注者的转推，说明叙事没打中，下次换"公共数据"角度，别重复发。

八、四个平台共同不能越的线

  • 不承诺结果。"能要回来""一定能拿到""包赢"这类话不能出现，书里本来就只写规则和怎么算，宣传跟着书走。
  • 不代替律师。不评价个案，不说"你这个情况应该怎么办"，只说"这条规定是怎么写的"。
  • 不写"免费领取"。它是公开网页，说"搜书名就能看"，不说"我发给你"。
  • 不放二维码、微信号、群号。四个平台都不放，包括 B站。
  • 不打扰别人。不 @ 大 V、不进互推群、不在别人的帖子下面贴链接。
  • C 级那 7 条不在任何宣传物料里当例子用。它们只查得到行业通行做法，拿去做钩子会被挑错，而且会把整本书的可信度拖下去。

九、把话说到底

这本书的读者不是"想读一本书的人"，是"今天遇到一件事、需要一个准确答案的人"。所以四个平台做的都是同一件事：在她遇到事的那一刻，被她搜到、被她看见、被她记住一个书名。

按这个标准，B站和 X 是现在就该做的，因为能测、而且来的人真的会下载；小红书是值得长期做的，一条一条攒搜索权重，半年后会有自然流量；抖音是可有可无的，做它只是为了让人搜书名的时候能搜到东西。

还有一句要记住：这本不是生意。没有课、没有社群、没有转化。KPI 不是销量，是有多少人真的用它算对了一次自己的账。宣传做得再热闹，如果读者点开发现打不开，或者打开发现读不完，前面全白费。
